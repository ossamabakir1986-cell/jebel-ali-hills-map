5. Labels, layers, and details

  • Display labels controls what text appears on the map labels, such as GIS, Master Plan, price, size, agent, phase, GFA, features, total, status, and last update.
  • Map layers controls the HD master plan, PA labels, and label color groups.
  • Details checklist controls which fields appear inside plot detail popups and copied details.
  • Apply Details View applies the selected popup/details fields.

6. Selected plots

The Selected Plots tools help you collect a group of plots before sharing or filtering.

  • Press Select Plots to start selecting plots from the map.
  • Click the plots you want to add to the selected list.
  • Use Show Selected Only to filter the map to only your chosen plots.
  • Use Copy Selected Details or Copy Selected Description to share selected plots with an agent or client.
  • Use Clear to remove selected plots, Reset to reset the view, and Apply to apply selected filters.
