Hayat GIS v3.3.54

This update keeps one unified toolbar inside the filter panel and strengthens Arabic/English translation coverage.

Main fixes:
- Arabic / Guide / What changed now load as one toolbar unit.
- Arabic mode translates selected visible controls including Display labels, Map layers, Details checklist, selected plots, Apply Details View, Hide, Reset, Apply, plot summary lines, and two-offer label dropdown text.
- Old stacked toolbar scripts are no longer loaded by the Admin/Agent inline loaders.
- English and Arabic guide pages now include a Selected Plots section.

No map inventory data was changed in this update.
